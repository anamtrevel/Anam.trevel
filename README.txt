ANAM TRAVEL — DATABASE SYSTEM

Files:
1) ANAM_TRAVELS_DATABASE_SYSTEM.html — mobile-friendly working prototype with browser database (localStorage), bookings, customer list, driver duties, vehicles/rates, feedback and JSON backup.
2) database.sql — SQL schema for moving the system to a real server database later.

How to use on a phone:
- Open the HTML file in Chrome.
- Data entered in the HTML app is stored on that browser/device.
- Use Database > Export JSON regularly as a backup.
- Import the JSON backup on the same app to restore data.

Important:
This HTML file is a local/browser database version, not a cloud multi-device database. The SQL file is the server-database foundation for a later Supabase/MySQL/SQLite deployment.
